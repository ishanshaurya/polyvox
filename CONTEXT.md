# PolyVox domain glossary

Product vocabulary (preferred in API/UI):

| Term | Meaning |
|---|---|
| Project / Engagement | One white-glove customer cohort with retention |
| Call | One recording + transcript + analysis |
| Agent | Person who handled the call |
| Rubric pack | KPI weights, escalation policy, training modules, disposition rules |
| Site | Location / brand label on a call (was often "hospital") |
| ArtifactStore | Seam for recordings, transcripts, analyses, reports |

Engine-internal terms still used in code: `stem`, `batch`, `pilot_agents`, `duration_bucket`, `cfg`.
