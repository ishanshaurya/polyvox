# Design assets

Drop frontend designs, mockups, and UI elements here.

Suggested layout:

```
design/
├── README.md          # this file
├── screens/           # page mockups (PNG/SVG/PDF)
├── components/        # buttons, cards, nav, tables
└── tokens/            # colors, typography, spacing notes
```

The web app lives in `apps/web/` and should implement these assets — do not invent a parallel design system until assets are here.
